# StageCast Pro — downloads

Installers for **StageCast Pro**, church presentation software for Windows (lyrics with chords for the band,
Bible verses in English and Tagalog, sermon slides, stage display and livestream lower thirds).

**Download:** [StageCast-Pro-Setup.exe (latest)](https://github.com/theharoldroyce/stagecast-releases/releases/latest/download/StageCast-Pro-Setup.exe)

- Windows 10 and 11, 64-bit.
- The installer isn't code-signed yet: if Windows says "Windows protected your PC", click **More info → Run anyway**.
- StageCast updates itself: it checks this page when it opens, downloads new versions in the background
  and asks you to restart.

This repository only holds the installers; it contains no source code.
